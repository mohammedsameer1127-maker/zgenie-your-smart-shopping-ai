# ZGenie: Your Smart Shopping AI

Build a modern, professional, AI-powered e-commerce web application named "ZGenie".

Theme:

- Light theme only.

- Clean, premium, minimal UI inspired by Apple, Stripe, and Notion.

- White background with subtle gray sections.

- Primary color: #2563EB (Blue)

- Accent color: #14B8A6 (Teal)

- Rounded cards (16px radius)

- Soft shadows

- Smooth animations

- Fully responsive for desktop, tablet, and mobile.

- Use modern typography (Inter/Poppins).

- Professional icons throughout.

- Avoid dark mode.

- Maintain consistent spacing and visual hierarchy.
